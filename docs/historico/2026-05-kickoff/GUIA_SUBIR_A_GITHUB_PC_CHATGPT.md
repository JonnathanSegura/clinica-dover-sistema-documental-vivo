# Guía rápida para subir Clínica Dover a GitHub Desktop y GitHub web

## 1. Descargar y descomprimir

1. Descarga el ZIP actualizado.
2. Descomprímelo en una carpeta fácil de ubicar, por ejemplo:
   - `Documentos/Clinica_Dover_Sistema_Documental_Vivo`
3. Entra a la carpeta y verifica que veas archivos como:
   - `README.md`
   - `INDICE_GENERAL.md`
   - `00-gobierno-del-proyecto`
   - `10-bitacora-diaria`

## 2. Abrir en GitHub Desktop

1. Abre GitHub Desktop.
2. Ve a `File` > `Add local repository`.
3. Selecciona la carpeta descomprimida del proyecto.
4. Si GitHub Desktop indica que no es repositorio, elige `create a repository`.

## 3. Configuración sugerida

Nombre del repositorio:

`clinica-dover-sistema-documental-vivo`

Descripción:

`Sistema documental vivo para estrategia digital, Growth, CRM, campañas, IA, reportes y portafolio profesional de Clínica Dover.`

Visibilidad sugerida inicial:

- Privado, si contiene información interna o documentos base.
- Público solo cuando se prepare una versión limpia sin datos sensibles.

## 4. Primer commit sugerido

Mensaje corto:

`Inicio oficial Sistema Documental Vivo Clínica Dover`

Descripción opcional:

`Se actualiza la estructura del proyecto con ruta de 3 chats, rol Líder de Marketing Digital y Growth, bitácora inicial, índice general y documentos base para iniciar el trabajo en GitHub.`

## 5. Publicar en GitHub web

1. Haz clic en `Publish repository`.
2. Verifica el nombre.
3. Decide si será privado o público.
4. Publica.
5. Entra a GitHub web y confirma que se ve el `README.md`.

## 6. Regla de trabajo diaria

Cada cierre de jornada debe terminar con:

1. archivo actualizado;
2. commit en GitHub Desktop;
3. push a GitHub web;
4. verificación en el navegador.
