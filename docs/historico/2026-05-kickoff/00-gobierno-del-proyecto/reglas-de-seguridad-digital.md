# Reglas de seguridad digital

## Accesos
- Solicitar usuario propio para WordPress, Meta Business, Google Ads, Analytics, Search Console, HubSpot y diseño.
- No usar contraseñas personales de terceros.
- No compartir claves por canales inseguros.

## WordPress
- Backup antes de cambios relevantes.
- Validar ambiente de pruebas si existe.
- Documentar cada cambio.
- Probar en móvil y escritorio.

## Datos personales
- Proteger datos de clientes y pacientes.
- No usar información real en portafolio público.
- Anonimizar evidencias.
