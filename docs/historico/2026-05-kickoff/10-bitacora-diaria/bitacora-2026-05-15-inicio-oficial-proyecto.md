Rol: Líder de Marketing Digital y Growth

## Contexto

Se inicia oficialmente el proyecto documental de Clínica Dover como sistema vivo para organizar estrategia digital, ejecución, reportes, bitácora, evidencias y portafolio profesional.

El proyecto se había planteado inicialmente con varios módulos temáticos, pero se decidió simplificar la operación conversacional en **3 chats principales** para evitar dispersión.

## Decisiones tomadas

1. El cargo queda definido como **Líder de Marketing Digital y Growth**.
2. El proyecto se trabajará en 3 chats:
   - `01 – Clínica Dover | Dirección y estrategia`;
   - `02 – Clínica Dover | Ejecución digital`;
   - `03 – Clínica Dover | Bitácora, reportes y portafolio`.
3. El repositorio conservará módulos internos por tema para organizar la evidencia.
4. La documentación debe servir tanto para ejecutar el trabajo como para construir un caso de estudio profesional.
5. El enfoque del rol no será solo publicar contenido, sino liderar captación, conversión, CRM, medición, IA y coordinación comercial.

## Impacto para el proyecto

Esta actualización convierte el sistema en una base más clara para iniciar el trabajo real en Clínica Dover. La estructura evita archivos sueltos y permite conectar estrategia, ejecución y evidencia profesional.

## Riesgo identificado

El principal riesgo sigue siendo mezclar responsabilidades: marketing puede generar oportunidades y trazabilidad, pero no debe cargar solo con cierre comercial, disponibilidad clínica, precios, agenda o retención.
