# 12 – Modelo replicable Marketing + CRM + IA

Este módulo documenta cómo el aprendizaje aplicado en Clínica Dover puede convertirse en un modelo replicable para otros negocios de servicios.

## Objetivo

Construir evidencia práctica para un sistema de marketing, CRM y automatización comercial con IA aplicable a pequeños negocios, profesionales independientes y empresas de servicios.

## Relación con Dover

Clínica Dover funciona como caso práctico de un negocio de servicios con ecosistema digital amplio: sitio web, redes sociales, formularios, WhatsApp, campañas, tienda, planes, sedes y equipo comercial.

## Relación con VALTERRA

VALTERRA funciona como caso B2B. Dover funciona como caso B2C/local de servicios. Juntos permiten comparar embudos, CRM, campañas, seguimiento y reportes.

## Uso futuro

Este módulo puede servir como evidencia para:

- portafolio profesional;
- servicios de marketing digital con IA;
- consultoría de CRM y automatización;
- propuesta comercial;
- posible proyecto para Fondo Emprender.

## Advertencia

No documentar datos confidenciales, historias clínicas, nombres de clientes, información sensible ni cifras internas sin autorización.
