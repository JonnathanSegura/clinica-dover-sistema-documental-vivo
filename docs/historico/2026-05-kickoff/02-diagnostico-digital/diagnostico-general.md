# Diagnóstico digital general

## Hallazgo central
La base digital existe, pero debe integrarse mejor para funcionar como sistema.

## Ruta ideal
Contenido / anuncio / búsqueda → sitio web / WhatsApp / formulario → HubSpot → seguimiento → cita / venta / servicio → reporte.

## Oportunidad principal
Convertir el ecosistema digital en un sistema medible de captación y seguimiento.
