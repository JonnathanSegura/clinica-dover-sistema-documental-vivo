# Pipeline Dover

| Etapa | Descripción |
|---|---|
| Lead nuevo | Contacto recibido |
| Contactado | Se respondió al usuario |
| Servicio identificado | Se conoce qué necesita |
| Cita agendada | Se agenda cita o servicio |
| Cita asistida | El cliente asistió |
| Servicio realizado | Se prestó el servicio o venta |
| Seguimiento posterior | Se realiza seguimiento |
| Cliente recurrente | Vuelve a usar servicios o tienda |
| Perdido | No respondió, canceló o no continuó |
