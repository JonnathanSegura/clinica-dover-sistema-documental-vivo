# KPIs por responsabilidad

No todos los indicadores deben recaer sobre marketing. Este documento separa lo que depende de marketing, comercial, dirección y operación clínica.

## KPIs de Marketing / Growth

| Indicador | Qué mide |
|---|---|
| Alcance | Cantidad de personas alcanzadas. |
| Impresiones | Número de veces que se mostraron anuncios o contenidos. |
| CTR | Porcentaje de clics sobre impresiones. |
| CPC | Costo por clic. |
| CPL | Costo por lead. |
| Clics a WhatsApp | Interés inicial hacia contacto. |
| Formularios enviados | Captación desde sitio web. |
| Llamadas generadas | Contacto directo desde campañas o web. |
| Conversión de landing | Capacidad de página para convertir tráfico. |
| Leads por servicio | Qué servicios generan más demanda. |

## KPIs del equipo comercial

| Indicador | Qué mide |
|---|---|
| Tiempo de respuesta | Rapidez de contacto. |
| Leads contactados | Porcentaje de leads atendidos. |
| Leads calificados | Prospectos con intención real. |
| Citas agendadas | Conversión comercial inicial. |
| Citas asistidas | Cumplimiento del cliente. |
| Cierres | Ventas, planes, consultas o servicios confirmados. |
| Motivos de pérdida | Razones por las que no se cerró. |

## KPIs de dirección / operación

| Indicador | Qué mide |
|---|---|
| Presupuesto aprobado | Capacidad real de ejecutar campañas. |
| Servicios priorizados | Foco comercial. |
| Disponibilidad de agenda | Capacidad para recibir demanda. |
| Experiencia de cliente | Satisfacción y retención. |
| Recompra o recurrencia | Relación posterior al primer servicio. |

## Lectura correcta

Marketing puede mejorar cantidad y calidad de oportunidades, pero la conversión total depende de todo el sistema: anuncio, página, WhatsApp, comercial, disponibilidad, precio, reputación y experiencia real del cliente.
