# 00 – Gobierno del proyecto

Este módulo define el alcance, las responsabilidades, los límites y las reglas de trabajo del Sistema Documental Vivo de Clínica Dover.

## Propósito

Evitar que el área digital funcione como tareas sueltas y convertirla en un sistema con responsabilidades, prioridades, medición y documentación.

## Archivos clave

- `alcance-del-proyecto.md`
- `rol-y-responsabilidades.md`
- `rol-lider-marketing-digital-growth.md`
- `limites-del-cargo-y-dependencias.md`
- `matriz-raci-marketing-comercial-clinica.md`
- `reglas-de-seguridad-digital.md`
- `bitacora-decisiones-estrategicas.md`

## Principio de gobierno

Sin alcance claro, el cargo puede convertirse en una suma de community manager, trafficker, analista, webmaster, CRM manager, copywriter y coordinador comercial. Por eso este módulo protege la ejecución y define límites medibles.
