# Clínica Dover — Sistema Documental Vivo

Sistema documental vivo del proyecto profesional **Clínica Dover**, bajo el rol de Marketing Digital, Growth, CRM, Automatización con IA y Transformación Digital.

Este repositorio funciona como la **fuente documental versionada** de captación, conversión, trazabilidad comercial, CRM, IA aplicada y transformación digital de la clínica — no como un depósito de archivos.

**Última reorganización:** 15 de agosto de 2026.
**Periodo documentado:** desde mayo de 2026 (kickoff del proyecto) hasta el 15 de agosto de 2026 (corte del histórico maestro).

## Principio del sistema

> Marketing genera y organiza oportunidades; el equipo comercial cierra; la operación clínica retiene.

Cada avance importante debe registrar: fecha, contexto, decisión tomada, acción realizada, evidencia disponible, impacto esperado y próximo paso.

## Seguridad documental — repositorio público

Este repositorio es **público** desde el 15/08/2026. Nunca debe contener contraseñas, tokens, API keys, credenciales, datos médicos de pacientes, ni datos personales identificables de clientes, proveedores o colaboradores. Ver `docs/10-procedimientos/seguridad-documental.md`.

## Metodología de trabajo

Fuente principal: el histórico maestro consolidado. Fuentes especializadas: documentos por tema cuando aportan más profundidad que el histórico. Regla: una información → una fuente principal → referencias desde otros documentos (se evita duplicar contenido completo entre archivos).
